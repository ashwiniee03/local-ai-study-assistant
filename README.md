# Local AI Study Assistant 🤖

A command-line AI chatbot built with **Python and Ollama**, powered by the Qwen3 language model.

This project is part of my hands-on journey into Generative AI. The goal is to understand how LLMs work in practical applications by building things from scratch before introducing frameworks such as LangChain and LangGraph.

The chatbot runs locally using Ollama, maintains conversation history, and supports customizable system prompts.

## ✨ Features

- **Local LLM Integration:** Interact with a locally hosted Qwen3 model using the Ollama API.
- **Conversation History:** Maintains user and assistant messages across multiple interactions, allowing the model to use previous conversational context.
- **Custom System Prompts:** Define the assistant's role, behaviour and instructions.
- **Interactive CLI:** Chat with the model directly through the terminal.
- **Graceful Exit:** Type `exit` to end the conversation.
- **HTTP Error Handling:** Handles request-related errors using Python's Requests exception handling.

## 🏗️ How It Works

The application communicates with Ollama through its local Chat API.

The basic workflow:

1. The user enters a message through the command-line interface.
2. The message is appended to the conversation history.
3. The application sends the complete message history to Ollama.
4. Ollama processes the request using the Qwen3 model.
5. The assistant's response is extracted from the API response.
6. The assistant's response is appended to the conversation history.
7. The conversation continues until the user enters `exit`.

### Conversation Structure

The application maintains messages using three roles:

- `system` – Defines the assistant's behaviour and instructions.
- `user` – Contains messages entered by the user.
- `assistant` – Contains responses generated by the model.

Example:

```python
messages = [
    {"role": "system", "content": "You are a helpful Python mentor."},
    {"role": "user", "content": "What is Python?"},
    {"role": "assistant", "content": "Python is a programming language."}
]
```

The complete message history is sent with each request so the model can use the previous conversation as context.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/ashwiniee03/local-ai-study-assistant.git

cd local-ai-study-assistant
```

### 2. Download the Qwen3 model

Pull the model using Ollama:

```bash
ollama pull qwen3:1.7b
```

### 3. Install project dependencies

Synchronize the project environment using uv:

```bash
uv sync
```

### 4. Run the application

```bash
uv run main.py
```

You can now start chatting with your local AI assistant!

## 💬 Usage

Start the application:

```bash
uv run main.py
```

Example interaction:

```text
Enter your query: What is Python?

Bot Response:
Python is a high-level, general-purpose programming language...

Enter your query: What are its main features?

Bot Response:
Python is known for its readability, simplicity...

Enter your query: exit
```

Type `exit` whenever you want to terminate the conversation.

## ⚠️ Limitations

- The chatbot currently uses a relatively small local language model.
- Model responses may contain inaccurate information or hallucinations.
- Conversation history is maintained in memory and is lost when the application exits.
- The application does not currently retrieve information from external sources.
- Response quality and speed depend on the available hardware and selected model.
